# Satchel 0.5.2

A fix for `report_answer` failing when an agent names the answer `answer` or `summary`.

> **Status:** pre-alpha. Expect breaking changes between 0.x releases. No migrations.

## Install

```bash
uv tool install satchel-server     # or: uv tool upgrade satchel-server
```

```bash
docker pull ghcr.io/getsatchel/satchel:0.5.2
helm upgrade satchel oci://ghcr.io/getsatchel/charts/satchel --version 0.5.2 -n satchel -f my-values.yaml
```

## Fixes

- **`report_answer` accepts `answer` or `summary` for `answer_summary`.** Agents sometimes used
  those names. The call failed validation and showed as an error step in the chat before the
  agent retried. They now map to `answer_summary`. `confidence` is still required.

## Upgrading from 0.5.1

Update the package or image and restart. On a VM, set `SATCHEL_IMAGE_TAG=0.5.2` in `.env`, then
`docker compose pull && docker compose up -d`. Start a new chat in Claude to pick up the new widget.

Everything in 0.5.0 and 0.5.1 applies: see the [0.5.0](0.5.0.md) and [0.5.1](0.5.1.md) release notes.
