# Satchel 0.5.4

One card per question. Claude showed a collapsed query card for every `run_sql` and
`query_metrics` call, then the answer card. Now it shows only the answer card.

> **Status:** pre-alpha. Expect breaking changes between 0.x releases. No migrations.

## Install

```bash
uv tool install satchel-server     # or: uv tool upgrade satchel-server
```

```bash
docker pull ghcr.io/getsatchel/satchel:0.5.4
helm upgrade satchel oci://ghcr.io/getsatchel/charts/satchel --version 0.5.4 -n satchel -f my-values.yaml
```

## Changes

- **Only `report_answer` draws a card.** `run_sql`, `query_metrics` and `get_result` show as the
  client's ordinary tool steps, and their results appear as tabs of the answer card. They still
  return the result payload, which the card uses for **Load more rows**. Their text tells the
  agent the user sees the rows in the answer card after `report_answer`.
- **No repeated title.** In the answer card, the result's title no longer repeats the headline.
  Tabs still name each result when there are several.
- **Two decimals in number tiles.** A number with no unit shows `34,838.20`, not `34,838.2`.
- **The demo model declares its currency.** In the Jaffle Shop example, `revenue` and
  `average_order_value` carry `"properties": {"currency": "AUD"}`, so they show as A$. Add the
  same to your own semantic model's money measures to get currency formatting.

## Upgrading from 0.5.3

Update the package or image and restart. On a VM, set `SATCHEL_IMAGE_TAG=0.5.4` in `.env`, then
`docker compose pull && docker compose up -d`. Start a **new chat** in Claude: an open chat keeps
the tool list it started with, and so keeps the old query cards.

Everything in 0.5.0 to 0.5.3 applies: see the [0.5.0](0.5.0.md), [0.5.1](0.5.1.md),
[0.5.2](0.5.2.md) and [0.5.3](0.5.3.md) release notes.
